# Clothing record workbooks

Small independent static browser tools by Jay Moo. The Render workbook identifies unresolved cost categories; the Firebase workbook distinguishes a received reply from an answered evidence question. Each directory contains a standalone index.html, with no build dependencies, server, database, analytics or account connections.

Deploy only the intended subdirectory to each host. Contextual guide references and the common maintainer's referral disclosure appear on the pages. The tools do not sell or certify products, handle payments, send messages, or change orders. AI-assisted editorial guidance; worked cases are illustrative rather than purchase reports.
